# Respaldo y recuperación

## Capas de protección

1. **OneDrive:** la bóveda principal se sincroniza desde `OneDrive/Desktop/Marlon Ortega/Conversaciones AI`.
2. **Git:** la carpeta de trabajo `Boveda de Obsidian` tiene un repositorio preparado para registrar cambios de organización.
3. **ZIP previo:** `OneDrive/Documents/ChatGPT/Boveda de Obsidian/Respaldos/Conversaciones AI - respaldo previo - 2026-09-19.zip`.

## Cómo restaurar

1. Cierra Obsidian.
2. Conserva la carpeta dañada con otro nombre; no la borres de inmediato.
3. Copia el ZIP a una carpeta temporal y extráelo.
4. Comprueba que existan el índice principal, las carpetas `01 - Proyectos` a `99 - Archivadas` y las conversaciones exportadas.
5. Abre la carpeta restaurada como bóveda en Obsidian.
6. Verifica enlaces y adjuntos antes de reemplazar la carpeta principal.

## Antes de cambios grandes

- [ ] Crear un ZIP con fecha.
- [ ] Comprobar que el ZIP abre.
- [ ] Registrar qué se va a cambiar.
- [ ] Mantener las conversaciones originales intactas.
